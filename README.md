# 烟花模拟器 🎆

一个基于 Canvas 的交互式烟花模拟器，纯前端实现，开箱即用。

## 在线演示

👉 **[https://itboy365.github.io/yanhua/](https://itboy365.github.io/yanhua/)**

点击页面任意位置，即可发射烟花。

## 功能特性

- 🎇 **真实的烟花效果**：粒子爆炸、重力下落、拖尾残影
- 🖱️ **交互式控制**：鼠标点击、触摸屏点击均可发射
- 🎨 **可自定义效果**：烟花颜色、大小、数量、爆炸样式
- 📱 **响应式设计**：PC、平板、手机全端适配
- ⚡ **零依赖**：纯 HTML + CSS + JavaScript，无需构建、无需服务器
- 🚀 **加载极快**：单文件部署，秒开

## 快速开始

打开 [`index.html`](index.html) 即可，无需任何环境。
